# Interfaz de AgroSense

Frontend de AgroSense construido con React, TypeScript, Vite y Tailwind CSS. La interfaz y los textos visibles están en español.

## Desarrollo

```powershell
npm install
npm run dev
```

La interfaz queda disponible en `http://localhost:5173`. La ruta `/dev/components` contiene la galería interactiva del sistema de diseño y `/dev/auth-preview` muestra la composición de autenticación.

## Validación

```powershell
npm run build
npm run lint
```
