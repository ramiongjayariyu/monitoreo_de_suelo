# Memoria del proyecto

## Contexto
AgroSense es una plataforma web de monitoreo de suelo. La interfaz, los mensajes, las notificaciones, los reportes y la documentación se desarrollan en español.

## Decisiones vigentes
- El monitoreo y el dashboard contemplan cinco variables: Humedad, pH, Salinidad, Temperatura del suelo y Temperatura ambiente.
- Los nombres visibles se presentan en español; los identificadores técnicos y las rutas conservan las convenciones definidas en `ARCHITECTURE.md`.

La programación y envío de reportes siguen aplazados hasta que se autorice configurar SMTP.
